# Erdos1196

Lean 4 / Mathlib formalization of all results in the arXiv preprint
["Primitive sets and von Mangoldt chains: Erdős Problem #1196 and beyond"](https://arxiv.org/abs/2605.00301)
by Boris Alexeev, Kevin Barreto, Yanyang Li, Jared Duker Lichtman,
Liam Price, Jibran Iqbal Shah, Quanyu Tang, and Terence Tao.

Formalized top-level results:

- Erdős--Sárközy--Szemerédi [#1196](https://www.erdosproblems.com/1196)
- Erdős primitive set conjecture [#164](https://www.erdosproblems.com/164)
- Odd Banks--Martin theorem
- 2 is Erdős-strong
- Ahlswede--Khachatrian--Sárközy inequality and LYM refinement
- Erdős--Sárközy--Szemerédi [#1217](https://www.erdosproblems.com/1217)
